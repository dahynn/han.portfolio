# Font sources

The cover and Hansol principles use Noto Sans KR, the typeface used by the Hansol corporate website. This is not a proprietary Hansol font.

- Website declaration: https://hansol.com/resources/css/font.css
- Regular: https://hansol.com/resources/font/NotoSansKR/NotoSansKR-Regular.woff2
- Black: https://hansol.com/resources/font/NotoSansKR/NotoSansKR-Black.woff2
- Noto Sans KR license: https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt (included as OFL.txt).

The CI page describes logo lettering separately; the supplied Hansol PNS logo remains an image asset. Helvetica Neue Light is used as a local-system preference for the small English management-system caption, with Helvetica and Arial fallbacks.
